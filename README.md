# canari · Garde chaque franc.

Carnet de caisse sur téléphone pour les petits commerçants de Côte d'Ivoire.
Toutes les décisions du projet sont dans [CLAUDE.md](CLAUDE.md).

## Où est l'appli ?

- `app/` : l'appli (page web installable qui marche sans internet).
- `images/` : mascotte et icône d'origine.
- `prototype/` : le prototype de référence.

L'appli est publiée automatiquement sur GitHub Pages à chaque mise à jour
(voir `.github/workflows/publier.yml`).
